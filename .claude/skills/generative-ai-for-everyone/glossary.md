# Glossary

**Activation function** — a non-linear function (sigmoid, Tanh, ReLU, GELU, softmax) applied to a neuron's output enabling a network to model non-linear relationships. (Ch 2)
**Agent (LLM)** — a software component letting an LLM decide which external tool to invoke and incorporate the result into its response (e.g., ReAct pattern). (Ch 7, Ch 8)
**AI alignment** — methods (continued pre-training, fine-tuning, RLHF, DPO, ORPO) that make a pre-trained model's behavior match task requirements and human preferences. (Ch 8)
**AI TRiSM** — AI Trust, Risk and Security Management; a Gartner-identified enterprise capability category for managing AI risk alongside GenAI applications and foundation models. (Ch 9)
**Anthropomorphization** — attributing human-like qualities/intentions to AI systems, risking overreliance or misplaced trust. (Ch 9)
**Artificial General Intelligence (AGI)** — AI with human-like general reasoning across domains. (Ch 1)
**Artificial Narrow Intelligence (ANI) / Weak AI** — AI trained for one specific task/domain, unable to generalize beyond it. (Ch 1)
**Artificial Super-intelligence (ASI)** — intellect substantially exceeding human cognition across nearly all domains (Bostrom's speed/quality/collective types). (Ch 1)
**Attention (self/cross)** — mechanism computing weighted relevance between tokens via Query/Key/Value projections; self-attention derives Q/K/V from the same sequence, cross-attention derives K/V from one sequence and Q from another. (Ch 5)
**Autoencoder** — an unsupervised encoder-decoder model that compresses input to a fixed latent vector and reconstructs it, minimizing reconstruction loss. (Ch 3)
**Backpropagation** — recursive application of the chain rule to compute gradients of a cost function with respect to every network weight/bias. (Ch 2)
**Batch normalization** — regularization technique normalizing layer inputs to zero mean/unit variance per mini-batch. (Ch 2)
**Benchmark leakage** — when an LLM is trained on data overlapping its evaluation benchmark, inflating reported scores. (Ch 8)
**Beam search** — a deterministic decoding strategy tracking k candidate sequences to find a high-probability overall sequence. (Ch 5)
**BERT** — Bidirectional Encoder Representations from Transformers; an encoder-only transformer pretrained via Masked Language Modeling + Next Sentence Prediction. (Ch 5)
**Bias-variance trade-off** — the balance between underfitting (high bias) and overfitting (high variance) in a model. (Ch 1, Ch 2)
**Byte-Pair Encoding (BPE)** — a sub-word tokenization algorithm (used by GPT) that iteratively merges frequent adjacent byte pairs. (Ch 5)
**Chain (LangChain)** — a reusable pipeline wrapping a prompt template and an LLM call, composable via SequentialChain. (Ch 7)
**Chain-of-Thought (CoT) prompting** — decomposing complex reasoning into intermediate steps within a prompt to improve arithmetic/symbolic task accuracy. (Ch 6)
**Classifier-free guidance** — a diffusion-model conditioning technique using random conditioning dropout during training and blending conditional/unconditional outputs at sampling (weight ω), avoiding a separate classifier. (Ch 4)
**CLIP (Contrastive Language-Image Pre-training)** — a model with paired image/text encoders trained to align image and text embeddings in the same space via contrastive loss. (Ch 4)
**Codebook (VQ-VAE/VQ-GAN)** — a learned finite set of discrete latent vectors that encoder outputs are snapped to, enabling discrete latent representations. (Ch 3, Ch 4)
**Confidential AI** — hardware-based Trusted Execution Environments (TEEs) protecting model/data confidentiality while data is "in use." (Ch 10)
**Continuous/in-flight batching** — serving technique executing multiple LLM inference requests concurrently without waiting for the whole batch to finish. (Ch 8)
**Convolutional Neural Network (CNN)** — a deep network using convolution/pooling layers to extract hierarchical image features. (Ch 3)
**Cosine similarity** — a distance metric measuring the angle between vectors, bound [0,1], used in clustering and embedding comparison. (Ch 1)
**Cross-entropy loss** — a classification loss function measuring divergence between predicted and true probability distributions. (Ch 2)
**CycleGAN** — a GAN variant for unpaired image-to-image domain translation, using cyclic-consistency loss. (Ch 4)
**DALL-E** — OpenAI's text-to-image generation model family. (Ch 4, Ch 6)
**Data drift** — model-performance degradation due to a shift in input data distribution over time. (Ch 8)
**Decoder-only architecture** — a transformer variant (GPT, LLaMA) using causal/masked attention for autoregressive text generation. (Ch 5)
**Decontamination** — removing benchmark test-set overlap from pre-training data to prevent benchmark leakage. (Ch 8)
**Deep learning** — a subset of ML using multi-layer artificial neural networks. (Ch 1)
**Denoising Diffusion Probabilistic Model (DDPM)** — a generative model that learns to reverse a forward Gaussian-noising Markov process, generating data from noise. (Ch 4)
**Diffusion model** — a generative model class (DALL-E 2, Stable Diffusion, Midjourney) that transforms data to noise (forward) and learns to reverse it (sampling). (Ch 4)
**Direct Preference Optimization (DPO)** — a preference-alignment fine-tuning technique using (chosen, rejected) response pairs without a separate reward model, cheaper than RLHF. (Ch 8, Ch 10)
**Discriminative model** — a model predicting p(y|x) (a label/class) as opposed to generating new data. (Ch 4)
**Disentanglement** — a latent-space property where changing one dimension affects only one semantic factor. (Ch 3)
**Distillation (knowledge)** — compressing a large "teacher" model's behavior into a smaller "student" model. (Ch 8)
**Double descent** — a phenomenon where over-parameterized models' test error decreases again past the classical interpolation threshold. (Ch 1)
**Drift (model)** — gradual shift in model performance due to changes in data distribution or input-output relationships (concept, data, prediction, prompt, upstream, embedding drift). (Ch 8)
**Embedding** — a fixed-size, lower-dimensional vector representation of data (text/image/audio) preserving semantic similarity. (Ch 1, Ch 5)
**Encoder-decoder architecture** — a transformer variant (T5, BART) using cross-attention to map one sequence to another. (Ch 5)
**Encoder-only architecture** — a transformer variant (BERT) using bidirectional attention to produce contextual representations. (Ch 5)
**Ensemble learning** — combining multiple models (bagging, boosting, stacking) to improve prediction accuracy/generalization. (Ch 1)
**Evidence Lower Bound (ELBO)** — the tractable loss bound (reconstruction + KL divergence) optimized in VAE and diffusion model training. (Ch 3, Ch 4)
**Federated learning** — decentralized training where raw data stays local and only model parameters/gradients are shared with a central server or peers. (Ch 10)
**Fine-tuning** — adjusting a pre-trained model's weights on task/domain-specific data. (Ch 1, Ch 8)
**FlashAttention** — an attention implementation optimizing GPU memory I/O to speed up computation. (Ch 8)
**Foundation model** — a large, transformer-based model pre-trained at scale, adaptable to many downstream tasks via prompting or fine-tuning. (Ch 2)
**GAN (Generative Adversarial Network)** — a generative model pairing a generator and discriminator in adversarial min-max training. (Ch 4)
**Gaussian Mixture Model (GMM)** — a probabilistic clustering model representing data as a mixture of Gaussian distributions. (Ch 1)
**GELU (Gaussian Error Linear Unit)** — a smooth activation function used in GPT-3/BERT-class models. (Ch 2)
**Generative AI (GenAI)** — the branch of deep learning producing new content (text/image/audio) rather than classifying existing data. (Ch 2)
**GPTQ** — an advanced post-training quantization technique for GPT-scale models using layer-wise compression. (Ch 8)
**Gradient descent** — an optimization algorithm iteratively updating weights in the negative-gradient direction to minimize a cost function. (Ch 2)
**Guardrails** — security controls (input/output filtering, policy enforcement) implemented throughout an LLM system to prevent unsafe behavior. (Ch 6, Ch 8)
**Hallucination** — GenAI generating plausible but factually incorrect or fabricated content. (Ch 2, Ch 9)
**Jailbreaking** — prompting techniques bypassing an LLM's built-in safety controls. (Ch 6)
**KV cache** — caching key/value attention vectors during autoregressive generation to avoid redundant recomputation. (Ch 8)
**Knowledge distillation** — see Distillation.
**LangChain** — an open-source LLM application framework providing chains, memory, document loaders, vector store integration, and agents. (Ch 7)
**Latent diffusion model (LDM)** — a diffusion model operating in a VAE's compressed latent space rather than pixel space (Stable Diffusion's approach). (Ch 4)
**Layer normalization** — normalizing inputs across all features within a layer (row-wise), as used in transformer blocks. (Ch 5)
**LLMOps** — standardized practices for building, deploying, managing, and monitoring LLM-based applications, split into Phase 1 (building) and Phase 2 (serving). (Ch 8)
**LlamaIndex** — an LLM framework specialized for retrieval-centric applications (search, summarization, auto-merging retrieval). (Ch 7)
**Long-Short Term Memory (LSTM)** — a gated RNN variant addressing vanishing gradients for long-term dependencies. (Ch 5)
**LoRA (Low-Rank Adaptation)** — a PEFT technique decomposing weight updates into low-rank matrices, drastically reducing trainable parameters. (Ch 8)
**Markov Decision Process (MDP)** — the formal environment model (state, action, reward, transition) underlying reinforcement learning. (Ch 1)
**Masked Language Modeling (MLM)** — BERT's pretraining objective: predict randomly masked tokens from context. (Ch 5)
**Memory (LangChain)** — components (buffer, window, token-limited, summary) giving an LLM application conversational continuity across turns. (Ch 7)
**Mixture of Experts (MoE)** — an architecture routing inputs to a subset of specialized expert sub-networks for sublinear compute cost. (Ch 1, Ch 8)
**Model card** — a standardized transparency document describing a model's purpose, data, performance, and limitations. (Ch 8)
**Model drift** — see Drift.
**Model merging** — combining multiple task-specialized models into one without additional training (linear, SLERP, task arithmetic, TIES, DARE, Frankenmerging). (Ch 8)
**Next Sentence Prediction (NSP)** — BERT's pretraining objective predicting whether two sentence spans are related. (Ch 5)
**Normalizing flow model** — a generative model built from invertible, differentiable transformations with tractable Jacobian determinants (Real NVP, GLOW). (Ch 4)
**Open Policy Agent (OPA)** — a policy-as-code tool enforcing authorization decisions within LLM API calls. (Ch 6)
**ORPO (Odds Ratio Policy Optimization)** — a preference-alignment technique combining language-modeling loss with an odds-ratio term, avoiding the need for a separate SFT stage. (Ch 8)
**OWASP Top 10 LLM vulnerabilities** — a common reference framework for LLM security risks. (Ch 8)
**PagedAttention** — a KV-cache memory-management technique using non-contiguous memory blocks to reduce GPU memory waste. (Ch 8)
**Parameter-Efficient Fine-Tuning (PEFT)** — fine-tuning techniques (LoRA, prefix tuning, P-tuning) updating only a small parameter subset. (Ch 8)
**Perplexity** — a metric measuring a language model's confidence/fluency in its predictions (lower is better). (Ch 8)
**Positional embedding** — a vector encoding a token's position in a sequence, added to word embeddings since attention is permutation-equivariant. (Ch 5)
**Prefix tuning** — a PEFT technique adding trainable prefix vectors to each transformer block's input while freezing base model weights. (Ch 8)
**Pre-training** — training a foundation model from scratch on massive, typically self-supervised, data. (Ch 8)
**Prompt engineering** — designing, testing, and optimizing input prompts to elicit desired LLM responses. (Ch 2, Ch 6)
**Prompt injection** — direct or indirect techniques manipulating an LLM's behavior via crafted or poisoned input. (Ch 6)
**Pruning (model)** — compressing a model by zeroing/removing near-zero weights or whole structures (unstructured vs. structured). (Ch 8)
**Quantization** — compressing model weights/activations to lower numerical precision to reduce memory/compute (PTQ, GPTQ, AWQ, GGUF). (Ch 8)
**RAG (Retrieval-Augmented Generation)** — grounding an LLM's output by retrieving relevant documents as context at query time. (Ch 5, Ch 7)
**ReAct (Reason + Act)** — an agent pattern combining reasoning with action, breaking a query into actionable sub-tasks. (Ch 7)
**Reinforcement Learning from Human Feedback (RLHF)** — aligning a model to human preferences by training a reward model from human ratings and optimizing the policy via PPO. (Ch 1, Ch 8)
**Representation learning** — learning a mapping from high-dimensional input to a meaningful low-dimensional latent space. (Ch 3)
**Residual/skip connection** — a shortcut passing information past intermediate layers, mitigating vanishing gradients (ResNet, U-Net, transformers). (Ch 3)
**Responsible AI** — ethical guidelines (transparency, fairness, accountability, privacy) embedded throughout the AI lifecycle. (Ch 9)
**Reparameterization trick** — expressing a stochastic latent sample as a deterministic function of parameters plus noise, enabling backpropagation through sampling. (Ch 3, Ch 4)
**RLAIF (Reinforcement Learning from AI Feedback)** — an RLHF variant using AI-generated (rather than purely human) feedback. (Ch 8)
**Sampling strategy (decoding)** — greedy, beam search, top-k, top-p (nucleus), temperature — methods for selecting the next token from a model's output distribution. (Ch 5)
**Semi-supervised learning (SSL)** — learning that combines a small labeled dataset with a large unlabeled one. (Ch 1)
**Sophia optimizer** — a second-order optimizer using a lightweight diagonal Hessian estimate, achieving ~2x LLM pre-training speedup over Adam. (Ch 10)
**Split learning** — distributed training partitioning a neural network at a "cut layer," with clients training up to the cut and the server training the rest. (Ch 10)
**Super-resolution GAN (SRGAN)** — a GAN architecture for upscaling low-resolution images to high-resolution using perceptual (content + adversarial) loss. (Ch 4)
**SLERP (Spherical Linear Interpolation)** — a pairwise model-merging technique treating weights as vectors on a hypersphere. (Ch 8)
**Tokenization** — splitting text into atomic units (word/character/sub-word) mapped to integer IDs for model input. (Ch 5)
**Tree-of-Thought (ToT) prompting** — a prompting technique exploring multiple reasoning branches with self-critique and search, extending Chain-of-Thought. (Ch 6)
**Transfer learning** — reusing a pre-trained model's weights/layers for a new, related task instead of training from scratch. (Ch 1)
**Transformer** — a self-attention-based neural architecture (encoder-only, decoder-only, or encoder-decoder) underlying modern LLMs; introduced in "Attention Is All You Need." (Ch 2, Ch 5)
**U-Net** — a symmetric encoder-decoder CNN architecture with skip connections, used for image segmentation and as the backbone of diffusion models. (Ch 3, Ch 4)
**Variational Autoencoder (VAE)** — a generative autoencoder learning a probability distribution over latent codes, optimized via ELBO. (Ch 3)
**Vector store / vector database** — a database optimized for storing and similarity-searching embedding vectors (Chroma, Pinecone). (Ch 7)
**vLLM** — a high-throughput, memory-efficient open-source LLM serving library using PagedAttention. (Ch 8)
**VQ-GAN** — a generative model combining GAN training with a VQ-VAE-style discrete codebook, followed by a transformer modeling codebook composition. (Ch 4)
**VQ-VAE** — a VAE variant using a discrete, learnable codebook instead of a continuous latent space. (Ch 3)
**Wasserstein distance (Earth Mover's Distance)** — a smoother distance metric than KL/JS divergence, used in WGAN to stabilize adversarial training. (Ch 4)
