# Glossary

**AGI (Artificial General Intelligence)** — theoretical, highly autonomous AI capable of generalizing across domains at or beyond human ability; not yet realized (Ch 6).

**AI (Artificial Intelligence)** — the broadest category: any system simulating human intelligence; no strict formal definition, so it includes ML, sequential logic, expert systems, and more (Ch 6).

**AI for Good** — a movement/mindset applying AI toward societal benefit (climate, healthcare, education, inequality) rather than purely profit-driven goals (Ch 8, Ch 9).

**ANN (Artificial Neural Network) / Deep learning** — ML subset using layered, weighted interconnected neurons inspired by the brain; includes CNN, RNN, LSTM, GAN, Transformer (Ch 6).

**API (Application Programming Interface)** — the formal contract specifying what data a client sends and how a server responds, enabling independent front-end/back-end development (Ch 7).

**Associative bias** — AI reproducing biased word/concept pairings learned from training data (e.g., men with leadership, women with caregiving) (Ch 8).

**Axis (Pandas)** — keyword controlling operation direction: `axis=0` = rows, `axis=1` = columns (Ch 5).

**Big O notation** — mathematical shorthand describing how an algorithm's time/memory scales with input size (Ch 4).

**Bias (AI)** — systematic skew in model outputs reflecting imbalance or prejudice in training data rather than ground truth (Ch 8).

**Bias amplification / feedback loop** — a cycle where biased AI outputs become future training inputs, magnifying the original bias over time (Ch 8).

**Boolean** — Python type representing True/False values (Ch 3).

**Bubble sort** — simple O(n²) sorting algorithm that repeatedly swaps adjacent out-of-order elements, "bubbling" the largest element to the end each pass (Ch 4).

**Class** — a blueprint for creating objects, defining attributes and methods (Ch 3).

**Client side** — the GUI/interactive layer a user directly touches (buttons, forms, images); built with HTML/CSS/JS, Swift, Kotlin, or auto-generated by Gradio (Ch 7).

**CNN (Convolutional Neural Network)** — an ANN architecture using convolutional/pooling layers to detect spatial image features, followed by fully connected classification layers (Ch 6).

**Colab (Google Colab)** — Google's free cloud-hosted Jupyter Notebook environment with GPU/TPU access and Google Drive integration (Ch 2).

**Container** — a lightweight, portable, self-sufficient bundle of code + runtime + dependencies ensuring consistent behavior across environments (Ch 7).

**DataFrame (Pandas)** — a two-dimensional labeled data structure (rows x columns), where each column is a Series (Ch 5).

**Data loader** — an object (e.g. Fast.ai `DataLoaders`) handling batching, shuffling, resizing, and augmentation of training data for a model (Ch 6).

**Debug log** — `print()` statements inserted inside loops/functions to expose intermediate state for understanding/troubleshooting algorithm behavior (Ch 4).

**Dictionary** — Python type storing data as key-value pairs (Ch 3).

**Dunder method** — a "double underscore" special method (e.g. `__init__`, `__str__`) automatically invoked by Python in specific circumstances (Ch 3).

**Dynamic typing** — Python's behavior of inferring a variable's type from its assigned value rather than requiring explicit declaration (Ch 1, Ch 3).

**Epoch** — one full pass of the training dataset through a model during training/fine-tuning (Ch 6).

**Error rate / accuracy** — a trained model's post-training performance metric; error rate + accuracy = 1 (Ch 6).

**Fairness-aware algorithm** — an algorithm explicitly designed to detect and correct biased patterns during training (Ch 8).

**Fast.ai** — a high-level Python deep-learning library/framework (built on PyTorch) that abstracts CNN setup/training into a few function calls (Ch 6).

**Filter bubble** — a personalization effect where recommendation algorithms repeatedly surface content aligned with past behavior, narrowing viewpoint exposure (Ch 8).

**Fine-tuning** — adjusting a pre-trained model's layers on a specific dataset rather than training all weights from scratch (Ch 6).

**Float** — Python type representing a decimal number (Ch 3).

**Function (`def`)** — a reusable, named block of code performing a specific task (Ch 3).

**Gradio** — a Python library that auto-generates a web GUI (and REST API) from a Python function, requiring no manual HTML/CSS/JS (Ch 7).

**GraphQL** — an API query style letting clients request exactly the data they need in one query, reducing over-/under-fetching (Ch 7).

**Groupby (Pandas)** — method that splits a DataFrame into groups by shared column value(s) for per-group aggregation (Ch 5).

**Hugging Face** — a platform for hosting/deploying AI models and Gradio-based web apps, abstracting server/container setup (Ch 7).

**Inference engine / learner object** — the exported, pre-trained model object used at deployment time to make predictions, without needing training data (Ch 6, Ch 7).

**Insertion sort** — O(n²) sorting algorithm that builds a sorted portion one element at a time, like sorting playing cards (Ch 4).

**Jupyter Notebook** — an interactive document format mixing executable code, output, and narrative text/Markdown in one file (Ch 2).

**LaTeX** — a markup syntax for rendering mathematical notation, usable inside Jupyter text cells (Ch 2).

**Learning rate** — the step size controlling how aggressively a model's weights update per training iteration; too high causes instability, too low causes slow training (Ch 6).

**List** — Python type storing an ordered, mutable sequence of items (Ch 3).

**LLM (Large Language Model) / GenAI** — a Transformer-based ANN subset designed to process/generate human language (e.g. GPT-4o) (Ch 1, Ch 6).

**Merge sort** — O(n log n) divide-and-conquer sort that recursively splits a list then merges sorted halves (Ch 4).

**ML (Machine Learning)** — a strictly defined AI subset: algorithms that learn patterns from data rather than following explicit programmer-written rules; must implement one of ~10 peer-reviewed algorithm families (Ch 6).

**None / NaN** — explicit "no value present" markers in Python/Pandas (`None` often for objects/strings, `NaN` for numeric), distinct from the general concept of "null"/missing data (Ch 5).

**Prompt engineering** — the practice of designing and refining inputs to get the best possible outputs from AI models; key aspects: precision, contextualization, adaptation, instruction-giving (Ch 1).

**Quick sort** — divide-and-conquer sort with average O(n log n), worst-case O(n²); partitions around a pivot and recurses (Ch 4).

**`raise`** — Python keyword that triggers an exception (e.g. `raise ValueError(...)`), halting normal execution unless caught (Ch 3).

**requirements.txt** — a text file pinning exact library versions needed for reproducible deployment (Ch 7).

**ResNet34** — "Residual Network, 34 layers," a common pre-trained CNN base architecture using residual/skip connections (Ch 6).

**REST API** — API style using standard HTTP methods (GET/POST/PUT/DELETE), typically returning JSON (Ch 7).

**Selection sort** — O(n²) sorting algorithm that repeatedly selects the minimum from the unsorted portion and swaps it into place (Ch 4).

**Sequential logic** — deterministic, explicit step-by-step programming logic (e.g. bubble sort, a calculator) where a given input always produces a predictable output (Ch 6).

**Series (Pandas)** — a one-dimensional labeled array (like a single spreadsheet column) holding one data type (Ch 5).

**Server side** — where core application logic, computation, and data access run, improving security/consistency/scalability versus client-side logic (Ch 7).

**`self`** — reference to the current instance inside a Python class method, used to access/set that instance's attributes (Ch 3).

**Stability (sorting)** — a sorting algorithm preserves the relative order of equal elements (Ch 4).

**Stereotyping (AI)** — a model reproducing societal stereotypes present in its training data (Ch 8).

**`__init__`** — the Python constructor dunder method, automatically invoked when a class instance is created, to initialize its attributes (Ch 3).

**`__str__`** — the dunder method defining an object's human-readable string representation, used by `print()`/`str()` (Ch 3).

**Time complexity** — a measure of how an algorithm's operation count grows as input size grows, used to compare algorithm efficiency (Ch 4).

**Training data bias** — bias arising from imbalanced or historically discriminatory training data (Ch 8).

**Transfer learning** — using a pre-trained model (e.g. ResNet34) as a starting point rather than training from scratch (Ch 6).

**Tuple** — Python type storing an ordered, immutable sequence of items (Ch 3).

**Variable** — a named container for data; Python infers its type from the assigned value (Ch 1, Ch 3).

**`while True`** — creates an intentional infinite loop, exited only via `break` or another explicit exit path (Ch 3).
