## Core Frameworks & Mental Models

**The Project Management Mindset (3 dimensions, 6 principles)** — Proactive (Adopt a Holistic View + Embed Quality Into Processes and Deliverables), Ownership (Be an Accountable Leader + Build an Empowered Culture), Value-Driven (Focus on Value + Integrate Sustainability Within All Project Areas). Use this as a first diagnostic lens on any struggling project.

**Principles → Performance Domains**: principles guide mindset/behavior; the seven performance domains (Governance, Scope, Schedule, Finance, Stakeholders, Resources, Risk) are where that mindset is demonstrated mechanically, via 40 underlying processes.

**Value delivery system**: Portfolio Management + Strategic Planning sit at the center, linking Organizational Strategy to Management of Programs/Projects and Operations/Products, inside an Internal Environment inside an External Environment — closed-loop feedback is what makes it work.

**Development Approach Spectrum**: Predictive ↔ Hybrid ↔ Adaptive, chosen via a factor checklist (ch04) and a "suitability filter" (ch13), never by default. The **inverted triangle**: in adaptive work, fix either (budget+schedule) or (scope) and let the other flex.

**Five Project Management Focus Areas** (not phases): Initiating, Planning, Executing, Monitoring & Controlling, Closing — recur and overlap throughout every phase/iteration, independent of development approach.

**Governance's three mandatory components**: target metrics + leading-indicator signaling + feedback mechanisms. Structured governance (sponsor/PMO/board/PM) fits predictive/large projects; self-governance (distributed accountability) fits adaptive, needing clear objectives+indicators+feedback to avoid fragmentation.

**Quality Assurance ≠ Quality Control**: QA = trusting the *process*; QC = verifying the *deliverable*. Keep as separate tracks.

**Scope = where value lives**: "the most important component of any project's baseline." Quality is a *feature of scope*. Use a Value Breakdown Structure (VBS) alongside the WBS to assign explicit value before decomposing.

**Earned Value Management (EVM)**: PV/EV/AC are the three primitives; everything else (CV, SV, CPI, SPI, EAC, ETC, VAC, TCPI) derives from them — full formula table in cheatsheet.md.

**Risk classification**: Known-Known (scope, not a risk) / Known-Unknown (classic risk) / Unknown-Known (hidden fact — someone else knows) / Unknown-Unknown (emergent — needs resilience, not a response plan). Five response strategies each for threats, opportunities, and overall project risk (cheatsheet.md).

**Measurement Pitfalls** (watch for all six before trusting any dashboard): Hawthorne effect, vanity metrics, demoralization, misusing metrics, confirmation bias, correlation-vs-causation.

**Two-dimension success assessment**: judge every project on outcome success AND process success *separately* — they can diverge sharply (Sydney Opera House = process failure/outcome success; Montreal overpass = process success/outcome failure).

**Tailoring is continuous**: Select approach → Tailor for organization → Tailor for project → Implement ongoing improvement — a loop, not a kickoff-only task.

**AI adoption tiers**: Automation (low-review) / Assistance (never trust first output) / Augmentation (iterative brainstorming partner) — match review rigor to tier; run the 7-point ethics check (bias/privacy/accountability/reliability/safety/transparency/copyright/sustainability) before scaling use.
