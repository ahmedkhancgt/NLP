# Chapter 17: Problem solving abilities (Quantitative)

## Core Idea
ChatGPT handles basic-to-intermediate quantitative work competently — the four arithmetic operations, integrations/derivatives/series expansion, probability/statistics, and simple logic puzzles — but is explicitly not yet reliable for hard-core, complex quantitative problems requiring deep specialized reasoning.

## Frameworks Introduced
- **Quantitative capability tiering**: Basic Math & Statistics (arithmetic, integration, derivatives, series expansion, probability, standard deviation) sits above Basic Logic & Reasoning (math puzzles, logical series, numerical patterns) in reliability, with hard-core complex problems explicitly out of reliable range.
  - When to use: setting expectations before delegating a quantitative task to ChatGPT.
  - How: classify the task as basic arithmetic/stats (high confidence), logic/puzzle-type (moderate confidence, "non-visual" only), or hard-core/research-level quantitative (low confidence) — and scale human verification effort inversely with that confidence tier.

## Key Concepts
- **Decision science**: an interdisciplinary field (math, statistics, economics, psychology) for structured, bias-mitigated organizational decision-making.
- **Data science**: the broader, higher-value career field encompassing AI/ML, strategic algorithms, visualization, and data interpretation — named by the authors as the most trending career path.
- **Quantitative problem-solving**: using data/statistical methods for objective, fact-based issue assessment rather than subjective judgment.
- **Visual reasoning limitation**: ChatGPT is explicitly weaker on tasks requiring interpretation of diagrams/graphs (visual pattern aptitude) compared to purely textual/numeric puzzles.

## Mental Models
- Use the **"objective/data-driven vs. subjective" framing** to pitch quantitative approaches: the chapter's core argument for quantitative methods generally (pattern-spotting via data/statistics) is the same argument for why ChatGPT is a credible assistant on these tasks specifically.
- Treat **"smaller to medium-level problems" as ChatGPT's quantitative sweet spot** — a useful calibration anchor before assigning it a task, especially in academic, interview-prep, or daily-practice contexts.

## Key Takeaways
1. ChatGPT reliably handles the four basic arithmetic operations plus calculus-level operations (integration, derivatives, series expansion) and core statistics (probability, standard deviation, variation).
2. It is capable but not fully trained for logic/aptitude-style puzzles, and explicitly weak on visual-pattern-based reasoning.
3. Elementary math/stats competence is framed as valuable beyond one-off problem-solving — as a building block for incrementally approaching more complex problems via iterative feedback.
4. Quantitative skill and decision/data science are framed as high-value career tracks the book treats as a motivating context for why these capabilities matter commercially.
