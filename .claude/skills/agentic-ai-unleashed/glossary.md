# Glossary

**A2A (Agent-to-Agent Protocol)** — Google's 2025 standard for agent-to-agent coordination; Client Agent discovers/communicates with Remote Agent via a JSON Agent Card over HTTP (Ch 3, 6, 18)
**ABAC (Attribute-Based Access Control)** — authorization from subject/resource/action/environment attributes rather than fixed roles (Ch 13)
**ACP (Agent Communication Protocol)** — standard for hosting/deploying agents that use built-in + custom tools; IBM's variant is merging into A2A (Ch 3, 6)
**Agency** — "the ability to drive purposeful change in the environment"; operationalized as perceive/recollect/plan/decide/act/adapt (Ch 1)
**Agent Card** — A2A's JSON capability-advertisement document (location, version, skills) for remote-agent discovery (Ch 3)
**Agentic application vs. impersonation** — agent acting ON BEHALF OF a user (logged distinctly, preferred) vs. acting AS the user (no audit distinction, discouraged) (Ch 13)
**AI-agent washing** — marketing basic automation as "advanced AI agents," the agentic analogue of greenwashing (Ch 3)
**Analogy reasoning** — inference via nearest-neighbor/kernel-regression similarity; the basis of RAG (Ch 2)
**Assumed breach** — security philosophy: architect for containment of successful attacks, not prevention alone (Ch 13)
**Attention mechanism** — transformer component giving global, parallel access across a sequence, solving long-range dependency (Ch 4)
**BDI (Belief-Desire-Intention)** — early agent architecture (Bratman); superseded due to no learning mechanism, poor multi-agent support (Ch 2)
**Base model** — raw pretrained LLM; fast, shallow, unaligned pattern-matching (Ch 4)
**Bayes' law** — `P(A|B) ∝ P(B|A)·P(A)`; posterior belief updating from prior and likelihood (Ch 2)
**BPI (Buffer Protection Index)** — CCPM metric: ratio of remaining buffer to remaining critical-chain length (Ch 9, cross-domain)
**Canary deployment** — staged rollout (0.1%→1%→10%→50%→100%) with success-gated progression (Ch 12)
**Capability firewall** — infrastructure-level (not agent-judgment) enforcement of action boundaries (Ch 13)
**Chain of custody (decision provenance)** — regulatory-grade record of data/decision sources enabling full decision reconstruction (Ch 13)
**Circuit breaker** — closed/open/half-open pattern that stops calling a failing dependency (Ch 9, 12)
**Cognitive core** — the LLM reasoning engine at an agent's center; necessary but not sufficient for agency alone (Ch 1, 4)
**Collective intelligence** — emergent problem-solving from groups of limited agents exceeding individual capability (Ch 17)
**Connectionist architecture** — DNN/transformer-based reasoning; winning paradigm for agentic cognitive cores (Ch 2)
**Constitutional AI** — training models to self-critique against written principles, reducing reliance on human feedback (Ch 2, 13)
**Continuous evaluation** — automated gold-standard-dataset scoring on every relevant code/prompt/model change, never one-time (Ch 10)
**CRDT (Conflict-free Replicated Data Type)** — data structure guaranteeing replica convergence regardless of message order (Ch 12)
**Critical path (CPM)** — DAG longest-path analysis determining end-to-end latency; optimize this, not task count (Ch 9)
**Decision trail recording** — multi-layered logging of an agent's intent interpretation, planning, and per-decision reasoning (Ch 11)
**Deduction vs. induction** — applying a world view (inference/deduction) vs. building one from observation (training/induction) (Ch 2)
**Delegation constraints** — delegated authority must be a strict, time-bounded, revocable subset of the delegator's own permissions (Ch 13)
**Deliberative agent** — builds internal model→plans→executes; slower, handles complexity (Ch 5)
**Distillation (knowledge)** — training a small student model to mimic a large teacher's soft+hard targets (Ch 9, 12)
**Embodied agent** — a physically-acting agent facing the reality gap between simulation and real-world physics (Ch 17)
**Emergent behavior** — system-level properties not predictable from individual components; requires stochasticity, nonlinearity, feedback, scale (Ch 5, 17)
**EVM (Earned Value Management)** — PV/EV/AC-based budget+schedule tracking; CV/SV/CPI/SPI/EAC/ETC/VAC/TCPI all derive from the three primitives (cross-domain)
**Explainability** — making agent behavior justifiable in human causal/motivational terms; distinct from transparency (Ch 14)
**Feature flag** — deployment/release decoupling toggle with an explicit lifecycle (dev→canary→permanent/removed) (Ch 12)
**Federated learning** — training without centralizing raw data; only aggregate updates leave the device (Ch 14, 16, 17)
**Function calling vs. tool calling** — manual low-level orchestration vs. framework-automated schema+execution+conversation management (Ch 6)
**Grounding** — anchoring LLM output in retrieved/real data rather than training-data "memory," fixing hallucination (Ch 4, 7)
**Hybrid architecture** — tiered cloud/gateway/edge processing matched to each cognitive function's latency/compute needs (Ch 12)
**Indirect prompt injection** — malicious instructions embedded in retrieved content (a webpage, email) rather than direct user input (Ch 13)
**Jailbreaking** — circumventing trained-in safety constraints via role-play, encoding, cognitive pressure, or multi-turn escalation (Ch 13)
**Knowledge distillation** — see Distillation
**Last-Write-Wins (LWW)** — simple CRDT conflict-resolution rule for preference-style data (Ch 12)
**Least privilege** — agents get only the minimum permissions needed, only when needed, only as long as needed (Ch 13)
**LLM-as-judge** — using a separate, independently-trained model to automatically score agent output quality (Ch 10)
**MAP rule (maximum a-posteriori)** — choosing the inference maximizing posterior probability; a special case of MEU under symmetric utility (Ch 2)
**MCP (Model Context Protocol)** — Anthropic's 2024 standard for agent-to-tool/data connectivity via client-server model (Ch 3, 6, 18)
**MEU (Maximum Expected Utility)** — the general rational-decision rule: choose the action maximizing `Σ P(s|d)·U(s)` (Ch 2)
**Mixture-of-Experts (edge pattern)** — a router loads only the relevant expert sub-network per inference, cutting peak memory (Ch 12)
**Multimodal integration** — synergistic (not additive) fusion of vision/language/audio/haptic perception (Ch 17)
**Observability vs. monitoring** — monitoring = predefined alerts (what went wrong); observability = contextual decision trails (why) (Ch 11)
**OOMKiller** — Linux kernel mechanism (not Kubernetes) that terminates processes under memory pressure (Ch 12)
**P95/P99 latency** — tail latency percentiles; the number that determines real deployment viability, not average (Ch 9, 12)
**Polymorphic attack** — LLM-generated, functionally-equivalent-but-textually-novel attack variants that defeat signature detection (Ch 13)
**Post-trained model** — base model + SFT/RLHF/safety training; the current agentic workhorse tier (Ch 4)
**Prompt hardening** — delimiter separation, instruction reinforcement, privilege markers to resist override attempts (Ch 13)
**Quantization** — reducing weight/activation precision (e.g., 32-bit→8-bit) for size/speed gains with modest accuracy cost (Ch 9, 12)
**RACI matrix** — Responsible/Accountable/Consulted/Informed responsibility assignment (cross-domain)
**RAG (Retrieval Augmented Generation)** — grounding LLM answers in retrieved real data rather than parametric "memory" (Ch 1, 7)
**Reactive agent** — direct stimulus→response, no planning; fast, predictable, limited (Ch 5)
**Reasoning model** — post-trained + chain-of-thought + multi-pass; slow, deep, state-of-the-art for complex logic (Ch 4)
**ReAct (Reason + Act)** — interleaving explicit reasoning steps with tool-calling actions; reduces hallucination (Ch 3)
**Reflection (self-correction)** — an agent erring, recovering via introspection tools, and retrying correctly without special engineering (Ch 7, 10)
**Reward hacking (specification gaming)** — satisfying an objective function's letter while violating its intent (Ch 14, 17)
**RBAC (Role-Based Access Control)** — granular, function-specific permission roles with inheritance and separation-of-duties rules (Ch 13)
**Score-threshold retrieval** — rejecting RAG matches beyond a distance threshold rather than returning the nearest-available wrong answer (Ch 18)
**Separation of duties** — rule that one agent may never hold two conflicting roles (e.g., approve+submit) (Ch 13)
**Social engineering (against agents)** — phishing/authority/urgency manipulation exploiting the same human-communication patterns agents are trained on (Ch 13)
**Span/trace** — a hierarchical, replayable record of every LLM call/tool invocation/memory operation in an execution (Ch 10, 11, 18)
**Speculative execution (edge)** — running multiple candidate inference paths concurrently, keeping the first to finish (Ch 9, 12)
**StatefulSet** — Kubernetes primitive giving stable network identity + persistent storage for long-running agents (Ch 12)
**Stigmergic communication** — environment-mediated coordination (e.g., pheromone trails) enabling swarm coordination without direct messaging (Ch 17)
**Structured output** — typed (e.g., Pydantic) agent responses instead of raw strings, enabling reliable downstream processing (Ch 4, 6, 18)
**T-shaped skill profile** — deep primary-discipline expertise plus cross-disciplinary breadth (Ch 17)
**Temporal RAG** — retrieval weighted/filtered by document recency for fast-changing domains (Ch 7)
**Value alignment** — ensuring agent goals/behavior accord with actual (not just stated) human intentions (Ch 14, 17)
**World model** — generative model combining physical laws + observational data to simulate physical dynamics (Ch 17)
