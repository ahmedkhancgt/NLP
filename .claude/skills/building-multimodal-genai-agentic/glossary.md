# Glossary

**Abductive reasoning** — Forming the best plausible explanation given incomplete observations; propose-and-verify pattern (Ch 12, 13)
**Adaptive index refresh** — Incremental/scheduled/event-driven reindexing to combat staleness and embedding drift (Ch 10)
**Adaptive RAG** — Dynamically selects retrieval/generation strategy based on query complexity/type (Ch 6)
**Agentic AI vs. AI agents** — Multi-agent, planning, persistent-memory systems vs. narrow, reactive, single-step task executors (Ch 5)
**Agentic RAG** — RAG with dynamic reformulation, multi-hop retrieval, and reflection (vs. static non-agentic RAG) (Ch 1, 6)
**ANN (Approximate Nearest Neighbor) search** — Trades exactness for speed in vector similarity search (HNSW, IVF, PQ) (Ch 1, 2)
**Auto-CoT** — Automatically generates Chain-of-Thought exemplars from existing QA pairs (Ch 13)
**Bi-encoder** — Independently encodes query and document into separate embeddings compared via cosine/dot product; fast, scalable (Ch 1, 2, 7, 9)
**BM25** — Sparse keyword-ranking function using term frequency and inverse document frequency (Ch 1, 3)
**Chain-of-Symbol (CoS) prompting** — Converts linguistic/spatial reasoning into symbolic representation (grids, tables) (Ch 12, 13)
**Chain-of-Thought (CoT) prompting** — Decomposing a task into explicit intermediate reasoning steps before the final answer (Ch 1, 12, 13)
**CLIP** — Contrastive Language-Image Pretraining; bi-encoder jointly embedding text and images into a shared latent space (Ch 2, 7, 9, 10, 13)
**ColBERT** — Late interaction model retaining token-level embeddings, scored via MaxSim (Ch 6, 9, 10)
**Corrective RAG (CRAG)** — Validates generated output against retrieved content, triggers correction on discrepancy (Ch 6)
**Cross-encoder** — Jointly encodes query and candidate with full cross-attention; accurate but expensive, used for reranking (Ch 1, 2, 6, 9)
**Deductive reasoning** — Drawing certain conclusions from true general premises via step-by-step logic (Ch 12)
**Embedding drift** — Degradation in how well current embeddings represent an evolving knowledge base (Ch 10, 18)
**Embedding normalization** — L2-normalizing vectors so cosine similarity depends only on angle, not magnitude (Ch 1, 10)
**Entity extraction** — Using an LLM for NER-style extraction to bridge unstructured text into structured/SQL-queryable form (Ch 14)
**Execution accuracy** — Text-to-SQL metric: does the generated SQL return the same result set as the reference? (Ch 14)
**Exact match accuracy** — Text-to-SQL metric: does generated SQL string-match the reference exactly? (Ch 14)
**Faithfulness** — Whether a generated answer is grounded in retrieved/source facts (vs. relevance = intent-alignment) (Ch 6, 18)
**Fallback and retry mechanism** — Layered strategies (clarify, refine prompt, simplify query, redirect, default template) for text-to-SQL failure recovery (Ch 14)
**Federated Query Engine (FQE)** — Execution layer (e.g., Trino) allowing one SQL query to span multiple heterogeneous databases (Ch 15)
**Few-shot prompting** — Including input/output examples in-prompt to elicit task-specific reasoning format (Ch 13)
**Fusion mechanisms (early/late/intermediate)** — Ways of combining modality information at input stage, output stage, or mid-pipeline via cross-attention (Ch 2)
**Generate-then-select** — Generate multiple reasoning paths/answers, then rerank/select (Ch 13)
**Genetic algorithm (GA) retrieval optimization** — Evolutionary search over retrieval configuration parameters guided by a fitness function (Ch 10)
**Global index** — Vector store (e.g., ChromaDB) of schema summaries/historical query patterns for schema matching across databases (Ch 15)
**Grading mechanisms** — LLM-based evaluators (retrieval relevance, hallucination, answer quality graders) inserted as pipeline checkpoints (Ch 6, 8, 15)
**Graph-of-Thoughts (GoT)** — Non-linear/cyclic reasoning structure generalizing Tree-of-Thoughts (Ch 13)
**HITL (Human-in-the-loop)** — Design pattern pausing agent execution for human review/approval before continuing (Ch 5)
**HNSW (Hierarchical Navigable Small World)** — Graph-based ANN indexing algorithm balancing recall and latency (Ch 1, 2, 6, 10)
**HyDE (Hypothetical Document Embedding)** — Embeds a generated hypothetical ideal-answer document to improve retrieval for abstract queries (Ch 6)
**Hybrid retrieval** — Combining sparse (BM25) and dense (vector) retrieval signals, merged via score fusion (Ch 1, 3, 6, 9, 10)
**Inductive reasoning** — Generalizing from specific examples to a probable rule (few-shot/in-context learning) (Ch 12)
**IVF (Inverted File Indexing)** — Vector indexing that clusters vectors and restricts search to relevant clusters (Ch 1, 2)
**LLM-as-a-judge** — Using an LLM to evaluate/rank/grade outputs of other AI systems via rubric-based prompting (Ch 8, 18)
**LLMOps / RAGOps** — Operational practices (deployment, monitoring, versioning, feedback loops) for LLM-based and RAG-based applications (Ch 18)
**Late interaction** — Independent encoding retaining token-level embeddings, compared at query time via MaxSim (middle ground between bi- and cross-encoders) (Ch 1, 6, 9, 10)
**Mathematical reasoning** — Arithmetic/algebraic/proof-based reasoning, best paired with tool-augmented (calculator/code interpreter) execution (Ch 12)
**MaxSim** — Similarity operation computing max cosine similarity per query token against document tokens, aggregated across tokens (Ch 6, 9, 10)
**Meta-reasoning** — Reasoning about generated responses themselves (plausibility, consistency, constraint satisfaction) (Ch 12)
**Modality-based routing** — Directing a query to the appropriate modality-specific index/model (Ch 1, 10)
**Model Context Protocol (MCP)** — Anthropic's open client-server standard exposing tools/resources/prompts over JSON-RPC (Ch 1)
**Multi-index embedding** — Maintaining separate, modality-specialized vector indexes rather than one undifferentiated index (Ch 9, 10)
**Multi-stage RAG** — RAG with additional stages beyond retrieve-generate: query expansion, multimodal/hybrid retrieval, reranking, validation, iterative feedback (Ch 6)
**Multi-vector representation** — Storing multiple (token/phrase-level) embeddings per document instead of one pooled vector (Ch 6, 10)
**Multimodal GenAI system** — Modular, retrieval-augmented pipeline spanning arbitrary modalities, vs. a single unified VLM (Ch 2)
**OCR foundation model** — Transformer trained end-to-end on visual+text, ingesting pixels directly (e.g., Mistral OCR) (Ch 16)
**Prefiltering threshold** — Score/rank cutoff narrowing candidates before expensive cross-encoder reranking (Ch 10, 15)
**Query expansion** — Broadening a query with synonyms/related terms to improve recall (Ch 1, 10)
**ReAct (Reasoning + Acting)** — Interleaving Thought/Action/Observation steps, grounding LLM reasoning in tool outputs (Ch 1, 3, 12, 13)
**Reciprocal Rank Fusion (RRF)** — Rank-based score fusion technique combining results from multiple retrievers (Ch 9, 10)
**Reranking** — Second-pass reordering of retrieved candidates using deeper relevance scoring (Ch 1, 6, 9, 10, 13)
**RLHF (Reinforcement Learning from Human Feedback)** — Using user ratings/corrections as a signal for feedback-aware retraining (Ch 18)
**Schema linking** — Mapping natural language phrases to exact database schema elements (explicit/implicit/fuzzy) (Ch 14, 15)
**Score normalization** — Min-max, z-score, or rank-based normalization needed before fusing incommensurable retrieval scores (Ch 9, 10)
**Self-consistency prompting** — Sampling multiple reasoning traces, selecting via majority vote (Ch 13)
**Self-RAG** — Model self-reflects on its own generated answer and re-retrieves/regenerates to improve (Ch 6)
**Spatial/Temporal reasoning** — Reasoning about geometry/layout or event order/duration, aided by symbolic/graph intermediate representations (Ch 12)
**STT/TTS (Speech-to-Text / Text-to-Speech)** — ASR models transcribing speech to text; neural vocoders synthesizing speech from text (Ch 11)
**Text-to-SQL** — Translating natural language queries into executable SQL statements (Ch 2, 14, 15)
**Tree-of-Thoughts (ToT)** — Exploring multiple reasoning paths as a structured decision tree (Ch 13)
**Typed CoT** — Assigning explicit reasoning types (causal, temporal, spatial) to each CoT step (Ch 13)
**Vision-Language Model (VLM)** — End-to-end unified model integrating vision and text (CLIP, BLIP, Flamingo) (Ch 2, 7, 9)
**Weighted embedding fusion** — Combining embeddings from different modalities with domain-appropriate weights rather than naive averaging (Ch 10)
**Zero-shot prompting** — Instructing a model with no in-prompt examples, relying on pretrained knowledge (Ch 13)
