# Glossary

**Accountability principle** — "You can never blame the LLM"; the builder owns outcomes (Ch11)
**Agent** — an LLM with tools, in a loop, pursuing a goal (Ch01, Ch02)
**ADLC (agent-building)** — five-phase lifecycle: Discovery→R&D→Development→Implementation→Maintenance (Ch11)
**ADLC (coding)** — using coding agents to build software via a lifecycle (Ch03)
**Agentic RAG** — agent decides when/how to call its own retrieval tool (Ch07)
**AgentCore** — AWS Bedrock's managed agent runtime suite: Gateway, Policy, Identity, Memory, Runtime (Ch11-15)
**AgentCore Gateway** — turns APIs into MCP tools, enforces Cedar policy per call (Ch12)
**AgentCore Memory** — managed long-term memory, four strategies, namespaced (Ch13)
**AGENTS.md** — entry-point file coding agents read at session start; progressive disclosure root (Ch03)
**Agent fleet/swarm/team** — org-wide roster / 20-100+ near-identical agents / 3-4 role-based agents (Ch09)
**Artificial Analysis / Pareto Front** — benchmark+cost chart; a shortlist tool, never a decision (Ch02)
**Autonomy dial** — per-action risk classification: Automatic, Approval-required, Prohibited (Ch11)
**Be the Boss** — demand evidence, never disclaim agent output as "not me" (Ch03)
**Cedar** — AWS's permit/forbid policy language on every gateway call; forbid always wins (Ch12)
**Checkpoint / Thread ID** — saved LangGraph state after a super-step / scoping key for its lineage (Ch08)
**Claude Agent SDK** — programmatic driver of Claude Code via `ClaudeAgentOptions` (Ch05)
**Cohen's Kappa** — rescales agreement vs. chance so a dominant-class guess scores 0 (Ch06)
**Compacting / Prompt caching** — rewriting history when context fills / discount on repeated prefix tokens (Ch02)
**Confusion matrix** — precision = TP/(TP+FP); recall = TP/(TP+FN) (Ch06)
**Context engineering** — constructing system prompt, state, retrieval, memory, tools, output format (Ch02, Ch05)
**Context layer** — what data means, how work is done, what agent may do (gateway), where data came from (Ch13)
**Context window** — hard cap on input+output tokens per call (Ch02)
**create_agent / create_deep_agent** — LangChain wrappers that build a LangGraph `CompiledStateGraph` (Ch02, Ch05, Ch08)
**Credential provider** — AgentCore Identity's stored secret, attached on outbound Gateway calls (Ch12)
**Decision model** — non-autoregressive transformer outputting a classification directly, e.g. Jev (Ch02, Ch10)
**Dense vs. MoE** — all params active per token vs. a router-selected subset of "experts" (Ch04)
**Dispatcher pattern** — no-LLM LangGraph graph fanning work to a bounded worker pool with retries (Ch09)
**Distillation** — training a small model on a big one's outputs; a real intelligence cut (Ch04)
**Durable execution** — a workflow that survives a crash/long wait and resumes exactly where it left off (Ch08)
**Edge (fixed/conditional)** — LangGraph connection; always fires vs. branches via routing function (Ch08)
**Embedding model** — converts text to a vector so similar meaning lands nearby (Ch07)
**Fan-out / Send** — distributing tasks to parallel node runs via `Send` objects (Ch09)
**FDE** — narrow: lab-employed engineer embedded at a client; broad: any applied AI engineer deploying LLMs (Ch01)
**Floor** — a hard minimum a metric must not fall below on held-out data (Ch10)
**GGUF / Safetensors / MLX** — local model file formats (Ollama/llama.cpp, Hugging Face, Apple Silicon) (Ch04)
**Handover / Handover conversation** — FDE makes self unneeded / a live five-question success-criteria demo (Ch11, Ch15)
**Harness / Harness engineering** — the scaffolding around a model; building that scaffolding deliberately (Ch01, Ch05)
**Held-out dataset** — data the improver never inspects; sole basis for keep/rollback (Ch10)
**HumanInTheLoopMiddleware** — `create_agent`-level gate on specific tool calls needing approval (Ch10)
**Idempotent node** — safe to re-run without double-firing a side effect (Ch08)
**IAM user vs. root** — narrow working account vs. all-powerful account (Ch11)
**Improver agent** — automates read→propose→evaluate→decide, optionally revises its own recipe (Ch10)
**interrupt() / Command(resume=...)** — pauses a node for human input; re-runs the whole node on resume (Ch08)
**Jev** — TypeSafe AI's decision model; calibrated confidence instead of free text (Ch02, Ch10)
**Langfuse** — observability: Traces, Datasets, Experiments, Scores (Ch06)
**LangGraph** — general dependency-graph engine: State, Nodes, Edges (Ch08, Ch09)
**Lethal Trifecta** — private data + untrusted content + external communication together (Ch12)
**LLM-as-a-judge** — a second model scores output, ideally against a reference answer (Ch06, Ch10)
**Long-term memory strategies** — semantic, preference, summary, episodic (Ch07, Ch13)
**Managed runtime** — hosting with built-in identity/memory, e.g. AgentCore (Ch11, Ch14)
**MCP** — tool protocol: host/client/server roles; stdio (local) or Streamable HTTP (remote) transport (Ch03, Ch07)
**Mistake-cost matrix** — business-agreed dollar cost per decision-error type (Ch06)
**Namespace partitioning** — hierarchical, code-enforced memory scoping (Ch13)
**Node** — a plain function in LangGraph: state in, state/update out (Ch08)
**Noise threshold** — minimum metric change treated as a real effect, not randomness (Ch10)
**Open-weight vs. open-source vs. proprietary** — weights only / weights+data+method / no release (Ch04)
**OpenRouter** — unified API gateway to many LLMs incl. a free tier; provider pinning via `extra_body` (Ch01, Ch04)
**Permission modes** — Manual, Accept Edits, Plan (now obsolete), Auto (default), Bypass/"YOLO" (Ch03)
**Playwright MCP server** — browser-automation MCP server for agent-driven UI testing (Ch03)
**Progressive disclosure** — short root docs; detail loaded only when relevant (Ch03)
**Quantization** — reducing parameter bit-width; near-free efficiency win (Ch04)
**Reducer / Super-step** — combines parallel node updates into one new state per turn (Ch08)
**RSI (recursive self-improvement)** — an agent improving how it improves; incremental today, not runaway (Ch05, Ch10)
**RetryPolicy** — LangGraph node-level automatic retry on exception (Ch09)
**RICE** — Reach, Impact, Confidence, Effort use-case prioritization (Ch11)
**RLHF / RLVR** — post-training behind the "chat" trick / the "reasoning" trick (Ch02)
**Sign off / Send back** — the two human resolutions for an above-threshold claim (Ch14)
**Six Tricks (GPT→ChatGPT)** — autoregression, chat, reasoning, illusion of memory, context, tool calling (Ch02)
**Spec-Driven Development** — driving a build from business-language markdown specs (Ch03)
**State** — immutable snapshot a LangGraph node consumes and replaces, never mutates (Ch08)
**Straight-through rate** — share of cases resolved without human referral (Ch06)
**Structured Outputs** — forcing LLM replies into a schema, rationale before decision (Ch02)
**Sub-agent reasons** — context isolation, independent check, cost efficiency, speed, security (Ch06)
**Three H's** — Harness, Hardening, Humans (Ch03)
**Three Traps** — "Agent for X," anthropomorphizing agents, plausible-vs-accurate (Ch06)
**Tool calling** — model requests a named function call; code executes it, never the model (Ch01)
**uv / uvx / npx** — Python package manager and isolated-run launchers for stdio MCP servers (Ch01, Ch07)
**Vibe coding** — trusting agent output without close inspection (Karpathy) (Ch03)
**Vector database** — indexes text by embedding for nearest-neighbor semantic search (Ch07)
