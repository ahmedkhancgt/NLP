# Glossary

**alias** — define a shortcut/macro for a command with fixed arguments, e.g. `l='ls -lhF'` (Ch 2)
**awk** — pattern-scanning and text-processing language; column-aware (`$1`,`$2`,`NR`) line processing (Ch 5)
**aws** — unified CLI for Amazon Web Services; used to list/manage EC2 instances for distributed `parallel` (Ch 8)
**bash** — GNU Bourne-Again Shell; the interpreter named in tool shebangs (`#!/usr/bin/env bash`) (Ch 4)
**bat** — `cat` clone with syntax highlighting, line numbers, and Git integration (Ch 2)
**bc** — arbitrary-precision command-line calculator, piped equations in (Ch 8)
**body** — applies a command to all but the first (header) line of CSV input (Ch 5)
**cat** — concatenate file(s) and print to stdout (Ch 2)
**cd** — change the shell's working directory (zsh builtin) (Ch 2)
**chmod** — change file permission bits, e.g. `chmod u+x script.sh` to make a tool executable (Ch 4)
**cols** — apply a command to only a named subset of CSV columns (Ch 5)
**column** — columnate/format lists into aligned output (Ch 2)
**cowsay** — draws an ASCII cow saying given text; used as a playful pipeline terminator (Ch 1)
**cp** — copy files/directories (Ch 2)
**csv2vw** — converts CSV to Vowpal Wabbit's `label | feature:value ...` format (Ch 9)
**csvcut** — select, exclude (`-C`), or reorder CSV columns by name/index (Ch 5, 7)
**csvgrep** — filter CSV rows by regex match on a named column (Ch 5)
**csvjoin** — SQL-like join of two CSVs on a shared key column (Ch 5)
**csvkit** — the CSV-aware tool suite (csvcut, csvgrep, csvjoin, csvlook, csvsort, csvsql, csvstack, csvstat, in2csv, sql2csv) (Ch 3, 5, 7)
**csvlook** — render CSV as a Markdown-style fixed-width console table (Ch 3)
**csvquote** — makes classic Unix tools (cut, awk) handle quoted CSV commas/newlines safely (Appendix)
**csvsort** — sort a CSV file by one or more columns (Ch 7, 8)
**csvsql** — execute SQL queries directly against CSV files (SQLite dialect) (Ch 5)
**csvstack** — stack rows of multiple CSVs into one, optionally tagging origin via a new column (Ch 9)
**csvstat** — per-column descriptive statistics (type, nulls, unique, min/max/mean/median/stdev) + row count (Ch 7)
**curl** — transfer data from/to a URL over 20+ protocols (HTTP, FTP, DICT, ...); the primary download tool (Ch 3)
**cut** — extract fields from each line by delimiter or character position; never reorders fields (Ch 5)
**data point** — one row (observation) in a dataset/CSV, excluding the header (Ch 9)
**display** — show an image file; four CLI display strategies exist (textual, iTerm2, viewer, browser) (Ch 7)
**dseq** — generate a sequence of dates (Ch 2)
**echo** — print text to stdout; often used to feed literal input into a pipeline (Ch 2)
**env** — run a program with a modified environment; `#!/usr/bin/env bash` makes shebangs portable (Ch 4)
**export** — mark a shell variable for use by child processes/tools (zsh builtin) (Ch 4)
**fc** — "fix command"; opens the last command in `$EDITOR` for editing (zsh builtin) (Ch 4)
**feature** — a column/property of a data point used by a model (Ch 9)
**find** — recursively search a directory tree by name, size, type, time, etc. (Ch 8)
**fold** — wrap long lines to a given width for display (Ch 9)
**for** — shell loop construct iterating over a list (numbers, files, words) (Ch 8)
**fx** — interactive JSON viewer/transformer (Appendix)
**geom (geometry)** — in ggplot2/rush, determines chart type (bar, histogram, density, boxplot, point, smooth, path) (Ch 7)
**git** — distributed version control tool; recommended companion to Make for project history (Ch 6)
**GNU Parallel (parallel)** — runs/distributes shell commands concurrently across cores or remote machines via SSH (Ch 8)
**grep** — print (or invert-print) lines matching a pattern/regex; `-i`,`-E`,`-v`,`-o` (Ch 2, 5)
**gron** — flattens/transforms JSON into greppable discrete assignment lines (Appendix)
**head** — print the first N lines of input (Ch 2)
**header** — add (`-a`), delete (`-d`), replace (`-r`), or apply-a-command-to (`-e`) a CSV header line (Ch 5)
**in2csv** — convert spreadsheets/other tabular formats to CSV (Ch 3)
**jq** — command-line JSON processor: query, filter, reshape, and pretty-print JSON (Ch 3, 5)
**json2csv** — convert JSON to CSV (Appendix)
**label** — the outcome/judgment column of a data point used by supervised models (Ch 9)
**less** — interactive, memory-efficient pager for inspecting files (`-S` disables wrapping) (Ch 7)
**ls** — list directory contents (Ch 2)
**Makefile** — the config file (`target: deps` + tab-indented rule) that `make` reads to build a workflow (Ch 6)
**make** — builds/reruns only stale targets of a declared dependency graph; formalizes reproducible workflows (Ch 6)
**man** — display a tool's manual page (Ch 2)
**mkdir** — create a new directory (Ch 2)
**mv** — move or rename a file/directory (Ch 2)
**nano** — simple terminal text editor used by `fc` in the Docker image (Ch 4)
**nl** — add line numbers to input (Ch 7)
**OSEMN** — Obtain, Scrub, Explore, Model, iNterpret: the book's five-step data science model (Ch 1)
**parallel** — see GNU Parallel (Ch 8)
**paste** — merge lines of multiple files side by side, or join lines of one file with a delimiter (Ch 5, 8)
**pbc** — "parallel bc"; wraps `parallel`+`bc` into a genuinely parallel calculator tool (Ch 8)
**pip** — Python package installer/manager (Appendix)
**placeholder ({})** — in GNU Parallel, denotes where/how input is inserted into a command (`{}`,`{1}`,`{/}`,`{.}`,`{#}`) (Ch 8)
**pup** — extract elements from HTML using CSS selectors (Ch 3, 5)
**pwd** — print the current working directory (Ch 2)
**python** — interpreted, general-purpose language; one of three tool-authoring languages covered (Ch 4)
**R** — statistical computing language/environment; invoked directly or via `rush` (Ch 7, 9)
**REPL** — read-eval-print loop; the command line's (and R's) immediate command-execute-feedback cycle (Ch 1)
**rev** — reverse each line character-wise (Appendix)
**rm** — remove files or (with `-r`) directories (Ch 2)
**rush** — "R one-liners from the shell"; `rush run` executes R/tidyverse expressions, `rush plot` creates ggplot2-based charts, both with minimal boilerplate (Ch 5, 7, 9)
**sample** — probabilistically filter stdin lines, with optional delay/duration, for debugging pipelines on large/streaming data (Ch 5)
**scp** — securely copy files to/from a remote machine over SSH (Appendix)
**sed** — stream editor for regex-based line filtering, substitution, and extraction (Ch 5)
**seq** — print a sequence of numbers (Ch 2)
**servewd** — serve the current directory over HTTP for browser-based image viewing (Ch 7)
**shebang (#!)** — first line of a script naming its interpreter, e.g. `#!/usr/bin/env bash` (Ch 4)
**shuf** — randomly permute input lines (used for train/test shuffling) (Ch 9)
**skll (run_experiment)** — SciKit-Learn Laboratory; config-file-driven CLI for training/evaluating scikit-learn classifiers (Ch 9)
**sort** — sort lines of text (often paired with `uniq -c`) (Ch 2, 5)
**split** — split a file into N roughly equal pieces, e.g. for train/test partitioning (Ch 9)
**sponge** — soaks up all stdin before writing to a file, enabling safe same-file read+write pipelines (Ch 2)
**sql2csv** — execute a SQL query against a database and emit CSV (Ch 3)
**ssh** — OpenSSH remote login client; the transport GNU Parallel uses for distributed processing (Ch 8)
**sudo** — execute a command as another (typically privileged) user (Appendix)
**tail** — print the last N lines of input, or all lines from line N onward (`-n +N`) (Ch 5)
**tapkee** — C++ dimension-reduction library/CLI (PCA, t-SNE, Isomap, LLE, MDS) (Ch 9)
**tar** — archive utility; `-xzf` extracts, `-tzf` lists a gzipped tarball's contents (Ch 3)
**tee** — write stdin to both stdout and a file simultaneously (Ch 2)
**telnet** — legacy remote terminal protocol client (used here only as a curiosity demo) (Ch 3)
**tldr** — community-maintained, example-first "cheat sheet" alternative to man pages (Ch 2)
**tr** — translate or delete individual (single-byte) characters (Ch 5)
**tree** — list directory contents recursively in a tree diagram (Ch 8)
**trim** — (dsutils) trims command output to a given terminal height/width for display (Ch 2)
**ts** — prefix each input line with a timestamp (Ch 8)
**type** — show whether a command is a builtin, alias, function, or binary, and where (zsh builtin) (Ch 2)
**uniq** — report or collapse adjacent repeated lines; `-c` adds counts (requires pre-sorted input) (Ch 2, 5)
**unpack** — auto-detects archive type by extension and calls the right decompression tool (Ch 3)
**unrar** — extract RAR archives (Ch 3)
**unzip** — list/extract ZIP archives (Ch 3)
**vw (Vowpal Wabbit)** — fast online-learning ML library/CLI; used here for regression (Ch 9)
**wc** — count lines/words/bytes of input (`-l`, `-w`, `-c`) (Ch 2)
**which** — locate the binary a command name resolves to (Appendix)
**xml2json** — convert XML/HTML input to JSON output (Ch 5)
**xmlstarlet** — command-line XML/XSLT toolkit (Appendix)
**xsv** — fast Rust-based CSV toolkit; `xsv count`, `xsv select` (Ch 5, 7, 9)
**zcat** — decompress and print gzip files without creating an intermediate uncompressed file (Ch 8)
**zsh (Z shell)** — the shell used throughout the book's examples (Ch 2)
